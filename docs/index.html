THE IDEA

Learn together. Share selectively.

A quality-gated L0–L3 hierarchy connects local skill learning, multi-user evolution, and task-aware retrieval.

01 / EXTRACT

Keep experience local

Extract L0 skills from both successful and failed sessions. Raw execution traces remain with contributors, rather than entering a shared trace pool.

02 / EVOLVE

Synthesize, then gate

Cluster related contributions and synthesize L1–L3. Five quality gates compare children with the strongest parent; rejected synthesis falls back to parents.

03 / RETRIEVE

Share useful knowledge

Release sanitized L1+ skills without private source or parent lineage. Receiving agents use static top-k injection or a dynamic librarian.

Compliance-oriented, not a privacy guarantee. Entity retention and source attribution are empirical exposure measurements, not differential privacy or cryptographic protection.

Four domains. Explicit evaluation conditions.

50Airline tasks
97Banking knowledge tasks
114Retail tasks
200Telecom tasks

Compare baseline, original L0, sanitized L1+, internal full-library static retrieval, and internal full-library dynamic retrieval. Qwen transfer reuses a fixed Sonnet source library; it does not learn a fresh library from Qwen traces.

Corrected reruns, not verified numerical reproduction. Raw traces, generated skills, results, logs, and human annotations are not bundled. Published numbers are historical; the current code does not establish reproduction of every paper result.

HANDS-ON / FROM ZERO

Try the code, one step at a time.

Start with credential-free offline checks. Continue to a command preview, and only then choose whether to run paid model-backed experiments. This is research code, not a hosted demo or a ready-to-install skill marketplace.

Prerequisites: Git, Python 3.12, and a terminal. Commands below use bash on Linux / macOS; Windows users can use Ubuntu in WSL. Run steps in the same shell. Installation requires internet access; offline checks need no API key or model weights.

  1. 01
    LOCAL · NO MODEL CALLS

    Clone and install

    Create an isolated environment in the repository root. If python3.12 is not found, install Python 3.12 first; use python --version after activation to confirm.

    bash
    git clone https://github.com/Arcs-ur/SkillLadder.git
cd SkillLadder
python3.12 -m venv .venv
source .venv/bin/activate
python --version
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
  2. 02
    OFFLINE · NO CREDENTIALS

    Run the offline checks

    These regression tests replace model calls and block socket connections. A successful run ends with a pytest summary of passed tests. This validates code behavior, not paper performance.

    bash
    python -m pytest -q -p no:cacheprovider
  3. 03
    OPTIONAL · BENCHMARK SETUP

    Prepare the pinned tau2 integration

    Continue only if you want to preview or run benchmark experiments. Use a new sibling checkout; apply the patch once. Install PortAudio headers before the Python extras, even for text-only tasks.

    Ubuntu / Debian only
    sudo apt-get update
sudo apt-get install portaudio19-dev
    macOS only · instead of the commands above
    brew install portaudio
    bash
    export TAU2_ROOT="$(cd .. && pwd)/tau2-bench"
git clone https://github.com/sierra-research/tau2-bench.git "$TAU2_ROOT"
git -C "$TAU2_ROOT" checkout 01e812d1d1c4df6d8d2299bf175e482527112244
git -C "$TAU2_ROOT" apply --check "$PWD/integrations/tau2/fedskill_tau2_integration.patch"
git -C "$TAU2_ROOT" apply "$PWD/integrations/tau2/fedskill_tau2_integration.patch"
python -m pip install -e "${TAU2_ROOT}[voice,knowledge]"
python scripts/check_tau2_integration.py --tau2-root "$TAU2_ROOT"

    Expected: the integration checker verifies the pinned revision, patched agent, retrieval behavior, logs, and all four task sets with model calls and sockets blocked. It downloads no embedding weights.

  4. 04
    DRY RUN · NO EXPERIMENT COST

    Preview the five conditions

    From the SkillLadder root, run the command below. The model names are placeholders for this preview, not executable provider IDs. --dry-run checks local paths and effective settings, prints commands, and creates no run artifacts or model requests.

    bash
    python scripts/run_tau2_comparison.py \
  --tau2-root "$TAU2_ROOT" \
  --config configs/paper.yaml --domain airline \
  --agent-model YOUR_LITELLM_SONNET_MODEL \
  --user-model YOUR_LITELLM_SONNET_MODEL \
  --skill-model YOUR_OPENAI_COMPATIBLE_SONNET_MODEL \
  --conditions baseline,l0-static,l1plus-static,full-static,full-dynamic \
  --output-dir output/airline --dry-run
  5. 05
    OPT-IN · PAID API CALLS

    Configure a real experiment

    Before removing --dry-run: load the values from .env.example into your shell (drivers do not load .env automatically). Set SKILLLADDER_API_KEY, SKILLLADDER_BASE_URL, and SKILLLADDER_MODEL for extraction / synthesis; configure tau2's OPENAI_* settings and actual LiteLLM agent / user IDs for your provider. Never commit credentials.

    Replace the placeholder model IDs above. Paper YAML requires strict embeddings: resolve the MiniLM model's weights commit and add --embedding-revision YOUR_WEIGHTS_COMMIT. Removing --dry-run sends requests and may download weights. Review provider costs and artifact-sharing policies first.

Troubleshooting & next experiments

Missing Python / package imports? Confirm Python 3.12, reactivate .venv, and install from the SkillLadder root. A PyAudio build failure usually means PortAudio headers are missing.

Patch already applied or wrong revision? Use a fresh tau2 checkout at the exact pinned commit. Do not apply the patch twice. Run the integration checker before previewing comparisons.

Authentication or strict embedding errors? Verify provider-specific IDs, exported environment variables, and the weights commit. Do not disable strict embeddings to claim a paper-equivalent result.

For banking_knowledge, retail, or telecom, change --domain; YAML selects the ordered task IDs. For Qwen transfer, AWM, resume, and audits, follow the full reproduction guide. These additional experiments are not part of the free offline tutorial.
