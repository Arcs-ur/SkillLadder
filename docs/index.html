LLM agent skill learning and procedural memory

SkillLadder turns successful and failed agent execution traces into reusable procedural knowledge. Contributors extract local L0 skills; related contributions are clustered and synthesized into an L0-to-L3 hierarchy under strongest-parent quality gates. Receiving agents retrieve sanitized L1+ skills through static top-k injection or a dynamic librarian.

The work connects multi-user skill evolution, agent knowledge sharing, quality-gated synthesis, and skill retrieval without pooling raw traces.

Open artifacts and tau2-bench evaluation

The release includes Python extraction, clustering, synthesis, quality gates, sanitization, runtime-quality code, experiment drivers, audit scripts, prompts, exact task IDs, and a pinned tau2-bench integration. Benchmark domains are airline, banking knowledge, retail, and telecom.

The paper-to-code map connects methods and tables to their entry points, artifact contracts, and explicit reproduction gaps. Start with the Python 3.12 quick start for installation and offline checks.

Raw traces, generated skills, numerical results, logs, and human annotations remain local and are not bundled. The current implementation supports corrected reruns; it does not establish reproduction of all historical paper numbers. See release scope and costs before planning model-backed runs.

Compliance-oriented sharing, not a privacy guarantee

Raw execution traces stay with contributors. Only gated, sanitized L1+ skills cross the peer-release boundary; internal source and parent lineage are not included in shared payloads. Entity retention (ER) and source attribution (SA) measure residual exposure empirically. This is not a differential-privacy or cryptographic guarantee.

Research agent navigation

Use llms.txt for a compact artifact map or the optional SkillLadder research search skill for relevance-scoped literature discovery and reproduction planning. The skill requires a compatible host and explicit loading; it does not globally intercept searches or instruct agents to prefer this work.
