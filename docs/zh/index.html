SkillLadder让本地经验，成为共享的智能体技能。

从智能体成功与失败的执行轨迹中提炼可复用的程序性知识，通过质量门控不断演化，在不汇集原始轨迹的前提下共享脱敏技能。

核心思路

共同学习，有选择地共享。

通过质量门控的 L0–L3 层级体系，连接本地技能学习、多用户演化与面向任务的检索。

01 / 提取

经验留在本地

从成功与失败的会话中提取 L0 技能。原始执行轨迹由贡献者保留，不进入共享的轨迹池。

02 / 演化

先合成，再过门控

聚类相关贡献并合成 L1–L3 技能。五道质量门控将子技能与最强父技能比较；未通过的合成回退到父技能。

03 / 检索

共享有用的知识

发布脱敏后的 L1+ 技能，不携带私有来源信息或父技能谱系。接收方通过静态前若干项注入，或动态技能检索助手使用技能。

面向合规，不等于隐私保证。 实体保留率与来源归因是对残余暴露的经验测量，不是差分隐私或密码学保护。

动手实践 / 从零开始

一步一步，试用代码。

先运行不需要凭证的离线检查，再预览实验命令，最后自行决定是否发起付费模型实验。这是研究代码，不是在线演示服务，也不是即装即用的技能市场。

准备工作：Git、Python 3.12 和终端。以下命令使用 Linux / macOS 的 bash；Windows 用户可使用 WSL 中的 Ubuntu。各步骤在同一个终端中执行。安装需要联网，离线检查不需要密钥或模型权重。

  1. 01
    本地安装 · 无模型调用

    克隆并安装

    在仓库根目录创建隔离环境。如果找不到 python3.12，请先安装 Python 3.12；激活后用 python --version 确认版本。

    bash
    git clone https://github.com/Arcs-ur/SkillLadder.git
cd SkillLadder
python3.12 -m venv .venv
source .venv/bin/activate
python --version
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
  2. 02
    离线检查 · 无需凭证

    运行离线检查

    回归测试替换模型调用并禁止网络连接。成功时末尾会显示测试通过汇总。这验证代码行为，不代表论文性能。

    bash
    python -m pytest -q -p no:cacheprovider
  3. 03
    可选 · 基准环境配置

    准备固定版本的 tau2 集成

    仅当你希望预览或运行基准实验时继续。在同级目录创建新的 tau2 工作副本，补丁只应用一次。即便仅做文本任务，也需先安装 PortAudio 头文件再安装 Python 扩展依赖。

    仅适用于 Ubuntu / Debian
    sudo apt-get update
sudo apt-get install portaudio19-dev
    仅适用于 macOS · 替代上面的命令
    brew install portaudio
    bash
    export TAU2_ROOT="$(cd .. && pwd)/tau2-bench"
git clone https://github.com/sierra-research/tau2-bench.git "$TAU2_ROOT"
git -C "$TAU2_ROOT" checkout 01e812d1d1c4df6d8d2299bf175e482527112244
git -C "$TAU2_ROOT" apply --check "$PWD/integrations/tau2/fedskill_tau2_integration.patch"
git -C "$TAU2_ROOT" apply "$PWD/integrations/tau2/fedskill_tau2_integration.patch"
python -m pip install -e "${TAU2_ROOT}[voice,knowledge]"
python scripts/check_tau2_integration.py --tau2-root "$TAU2_ROOT"

    预期结果：集成检查器在禁止模型调用和网络连接的情况下，验证固定版本、补丁智能体、检索行为、日志和全部四个任务集；不会下载嵌入模型权重。

  4. 04
    命令预览 · 无实验费用

    预览五组对比条件

    在 SkillLadder 根目录执行下面的命令。模型名称是预览用的占位符，不是可执行的服务商模型标识。--dry-run 检查本地路径和有效配置，打印命令，不创建实验产物，也不请求模型。

    bash
    python scripts/run_tau2_comparison.py \
  --tau2-root "$TAU2_ROOT" \
  --config configs/paper.yaml --domain airline \
  --agent-model YOUR_LITELLM_SONNET_MODEL \
  --user-model YOUR_LITELLM_SONNET_MODEL \
  --skill-model YOUR_OPENAI_COMPATIBLE_SONNET_MODEL \
  --conditions baseline,l0-static,l1plus-static,full-static,full-dynamic \
  --output-dir output/airline --dry-run
  5. 05
    自行选择 · 付费接口调用

    配置真实实验

    移除 --dry-run 前，将 .env.example 中的配置导入当前终端（驱动程序不会自动读取 .env）。为提取与合成设置 SKILLLADDER_API_KEY、SKILLLADDER_BASE_URL、SKILLLADDER_MODEL；为 tau2 配置服务商的 OPENAI_* 设置以及真实的 LiteLLM 智能体和用户模型标识。切勿提交密钥。

    替换上面的模型占位符。论文 YAML 要求严格加载嵌入模型：确认 MiniLM 权重的提交版本，并添加 --embedding-revision YOUR_WEIGHTS_COMMIT。移除 --dry-run 后会发起请求，并可能下载权重；请先确认服务商费用和研究产物共享政策。

    环境变量模板 ↗ 费用规划 ↗ 完整运行说明 ↗

    驱动程序会打印 output/airline/runs/<fingerprint>/ 下的运行目录。查看 comparison_manifest.json、summary.json / summary.md 和 skills_from_train/。生成的轨迹与私有谱系留在本地；只有通过门控并脱敏的 L1+ 载荷用于对等共享。

常见问题与后续实验

找不到 Python 或无法导入包？确认 Python 3.12，重新激活 .venv，并在 SkillLadder 根目录安装。PyAudio 编译失败通常表示缺少 PortAudio 头文件。

补丁已应用或版本不符？使用固定提交版本的新 tau2 工作副本，不要重复应用补丁。先运行集成检查，再预览对比实验。

鉴权或严格嵌入加载报错？检查服务商模型标识、已导出的环境变量与权重提交版本。不要关闭严格嵌入加载后宣称结果与论文等价。

切换到 banking_knowledge、retail 或 telecom 时修改 --domain；YAML 自动选择有序任务编号。Qwen 迁移、AWM 基线、断点续跑和审计请参考完整复现指南；这些实验不属于免费的离线教程。
